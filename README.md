# Speed Dating en español

Actividad táctil para las jornadas de puertas abiertas del Spanish Programme de HKU. Permite practicar presentaciones, procedencia, lenguas, residencia y gustos mediante tarjetas visuales.

## Desarrollo

- `npm run dev:pages`: vista previa de la versión estática.
- `npm run build:pages`: crea la web que se publica en GitHub Pages.
- `npm test`: compila y comprueba el contenido esencial.

El catálogo editable se encuentra en `src/data/content.ts`.
